## Restore a source bundle

```bash

# or
git clone zu-chiangmai-main.bundle
```

Verify every file against `checksums.sha256` before using an artifact. Parallel uncommitted work is intentionally not included; bundles contain committed history only.

## Consent boundary

Shaka has confirmed full broadcast and sharing consent for the recording, but the raw video file and the full participant transcript are not attached to this archive. Private Meet/Drive links, attendee lists, emails, wallet mappings, secrets, and unapproved personal cards are not included. Public-safe notes and launch receipts are included. See the Octave report and https://opensourceorchestra.org/takedown/.
