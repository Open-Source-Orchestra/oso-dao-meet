Grow the public media files

This is how the Open Source Orchestra DAO’s public media grows: a circle meets, the notetakers enter first, consent is asked out loud on the recording, the host hits record last, nothing is cut, and nothing goes public until everyone has said yes and the transcript has been checked. Then the file is added here — video, audio, captions, transcript, status JSON — for anyone to play and verify. Record your circle the same way and add yours: join the road, read the PIT protocol · publicinform, and keep the takedown door open.
