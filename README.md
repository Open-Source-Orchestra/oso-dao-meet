# Open Source Orchestra DAO Meet

**Canonical home:** https://osodaomeet.opensourceorchestra.org/

A living virtual orchestra hall, clickable slide deck, and future consent-gated listening archive for the Open Source Orchestra DAO First Circle.

## Honest status

- The Open Source Orchestra DAO is a **proposal and community ledger, not yet an on-chain DAO**: https://opensourceorchestra.org/dao/
- The First Circle is consent-based. No person becomes a formal member by being shown or invited.
- Every contribution is equal. Agents draft and maintain; agents have no votes, keys, Shamans, or unilateral execution.
- The third Open Source Orchestra DAO Meetup is intended to be **open-invite for everyone**. Public details will appear only when confirmed.
- No current private Google Meet links, attendee data, wallet mappings, transcripts, or meeting recordings are stored here.
- Future transcript and recording downloads remain unavailable until Shaka's blessing and every required participant consent are explicitly recorded. Takedown: https://opensourceorchestra.org/takedown/

## Build

Static HTML, CSS, JavaScript, and locally vendored Three.js. No build step, trackers, runtime CDN, wallet integration, token sale, or autoplay audio.

```bash
python3 -m http.server 8080
# open http://localhost:8080/
```
